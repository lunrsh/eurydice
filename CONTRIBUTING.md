# Contributing to Eurydice

This is a draft, but it should be enough to give you general guidance. More information will be added soon.

## Getting an Account on This Forgejo Instance

First, you would need to register an account on Forgejo. However, your account needs to be manually confirmed by me for spam. To do this, email me at <luna@lunr.sh>, with the subject line `[Forgejo Account Confirmation]` (or something similar), with your account username in the body of the email. You should send the email from the same email you used for the account, if possible.

## Issues

If you find a bug or have a feature request, please open an issue on the [issue tracker](https://git.lunr.sh/eurydice/eurydice/issues), and use the provided issue template to describe your issue.

## AI Policy

This project follows the [Forgejo AI Agreement](https://codeberg.org/forgejo/governance/src/branch/main/AIAgreement.md). Make sure you understand it before opening a pull request.
