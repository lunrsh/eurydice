# Contributing to Eurydice

Thank you for wanting to contribute to Eurydice! There are some recommendations and guidelines you should follow before continuing, however:

## Getting an Account on This Forgejo Instance

First, you would need to register an account on Forgejo. However, your account needs to be manually confirmed by me for spam. To do this, email me at <luna@lunr.sh>, with the subject line `[Forgejo Account Request]` (or something similar), with your account username in the body of the email. You should send the email from the same email you used for the account, if possible.

## Issues

If you find a bug or have a feature request, please open an issue on the [issue tracker](https://git.lunr.sh/eurydice/eurydice/issues), and use the provided issue template to describe your issue.

## Pull Requests

When you are ready to submit a pull request, you may make one at [the pull requests page](https://git.lunr.sh/luna/eurydice/pulls). Be sure to have backing issue(s) with more information (explained more on the pull request template).

## AI Policy

This project follows the [Forgejo AI Agreement](https://codeberg.org/forgejo/governance/src/branch/main/AIAgreement.md). Make sure you understand it before opening a pull request.
